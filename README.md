# Invoice Studio

A simple invoice generator that runs entirely in the browser. No server, no sign-in.

- Create invoices with logo, customer, items, VAT, order number and payment details
- Saved customers and items, document list with search and payment status
- Download invoices as PDF or Word, backup and restore your data
- Works offline and can be added to the iPhone Home Screen

All data is stored in the browser on the device you use. Nothing is sent anywhere.

## Run it
Open `index.html` through any web host (GitHub Pages, Netlify, etc.).

## Files
- `index.html` the whole app
- `lib/` PDF and Word libraries and fonts (bundled so it works offline)
- `icons/`, `manifest.webmanifest`, `sw.js` app icon, install info and offline support
